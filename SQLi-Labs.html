Lab 01: SQL injection vulnerability in WHERE clause allowing retrieval of hidden data

Descripción del laboratorio

Este laboratorio contiene una vulnerabilidad de inyeccion de SQL en el filtro de categoria de productos. Cuando el usuario selecciona una categoría, la aplicación ejecuta una consulta SQL como la siguiente:

SELECT * FROM products WHERE category = 'Gifts' AND released = 1

Para resolver el laboratorio, se debe realizar un ataque de inyección SQL que haga que la aplicación muestre uno o más productos no lanzados.

Tipo de vulnerabilidaad: SQL Injection basada en manipulación lógica (Boolean-Based SQL Injection) en la cláusula WHERE.

Solucion del laboratorio

Los siguientes pasos fueron necesarios para la realizacion de este laboratorio

  1. Con Burpsuite, interceptar y modificar la solicitud que establece el filtro de categoría de producto.
  2. Modificar el parámetro de categoría, dándole el valor '+OR+1=1--'.
  3. Enviar la solicitud y verificar que la respuesta ahora contenga uno o más productos no publicados.
