Análisis de servicios de seguridad

Introducción

Este documento tiene como objetivo analizar diferentes escenarios de incidentes de seguridad informática mediante la aplicación de los servicios definidos dentro del ITU - T X.800, así como hacer uso correcto de la terminología de RFC 4949, con el propósito de poder identificar, explicar y documentar vulneraciones de seguridad en contextos reales.

Resumen de los escenarios

En esta sección presentamos una vista resumida de todos los diferentes escenarios, tomando como base un análisis bajo los marcos X.800 y RFC 4949.

Escenario Clasificación X.800 Categoría RFC 4949 Medidas de Control
1. LockBit C I D Multi-stage / Data Breach Respaldos inmutables
2. Nube mal config. C Misconfiguration / Exposure Control de acceso
3. Supply chain I Supply chain attack Detección de intrusiones
4. Phishing/Creds Autenticación Credential compromise MFA (Multifactor)
5. Destrucción Backup D Data destruction Backups offline
6. Amenaza interna C Insider threat Mínimo privilegio
7. Alteración Logs NR I Audit trail violation Logs de solo escritura
8. Falla operacional D Operational failure Rollbacks
9. Masquerade Autenticación Phishing / Masquerade Concientización
10. Ataque destructivo C I D Destructive attack Plan de recuperación (DRP)

Conclusiones

El desarrollo de esta actividad sirve para la comprension de diferentes tipos de ataques, considero interesante saber los diferentes tipos de ataques, puesto que no solo estamos expuestos a hackers, si no que tambien a riesgos internos o campañas de desinformacion.
