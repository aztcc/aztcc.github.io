Mecanismos de defensa en la red

1. Introduccion

En la seguridad de redes modernas, el enfoque más robusto es el de "Default Deny" (Denegación por Defecto). Este principio establece que todo tráfico de red está prohibido a menos que exista una regla explícita que lo permita.

Configurar un firewall no es solo abrir puertos, sino gestionar el estado de las conexiones y la superficie de exposición. Al implementar políticas restrictivas tanto en la entrada (INPUT) como en la salida (OUTPUT), transformamos el servidor de un elemento pasivo a una barrera activa contra exfiltración de datos, movimientos laterales de malware y accesos no autorizados desde Internet.

2. Descripcion de la actividad

Esta actividad consiste en el diseño y despliegue de un esquema de seguridad perimetral mediante el uso de un firewall de filtrado de paquetes (iptables). El objetivo principal es transitar de una red abierta y vulnerable hacia una arquitectura de Confianza Cero (Zero Trust) a nivel de red, donde todo tráfico es inspeccionado y validado según su origen, destino y propósito.

3. Comandos utilizados

1. Establecer una política restrictiva.

iptables -A INPUT -p tcp -j REJECT

2. Permitir el tráfico de conexiones ya establecidas.

Iptables -A INPUT -p tcp -s 192.1.2.10, 192.1.2.11 -j ACCEPT

3. Aceptar tráfico DNS (TCP) saliente de la red local.

Iptables -A OUTPUT -p tcp -s 192.1.2* - ACCEPT

4. Aceptar correo entrante proveniente de Internet en el servidor de correo.

Iptables -A INPUT -p tcp -s 192.1.2.10 - -dport 587 -j ACCEPT

5. Permitir correo saliente a Internet desde el servidor de correo.

Iptables -A OUPUT -p tcp -s 192.1.2.10 - -dport 587 -j ACCEPT

6. Aceptar conexiones HTTP desde Internet a nuestro servidor web.

Iptables -A INPUT -tcp -s 192.1.2.11 - -dport 80 -j ACCEPT

7. Permitir tráfico HTTP desde la red local a Internet.

Iptables -A FORWARD -tcp -s 192.1.2.11 - -dport 80 -j ACCEPT

4. Conclusiones

La configuración realizada demuestra que un firewall efectivo no es una lista estatica de puertos abiertos, si no que tambien un sistema dinamico que entiende el contexto de la comunicación.
