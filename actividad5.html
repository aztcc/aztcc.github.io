Cartografiando el pentesting

1. Introducción

El propósito de esta actividad es el de analizar y comparar de manera estructurada las principales metodologías y marcos de referencia utilizados en pruebas de penetración y evaluación de seguridad informática, con el fin de que el estudiante comprenda sus enfoques, objetivos contextos de aplicación y alcances técnicos, fortaleciendo su criterio para seleccionar y aplicar la metodología mas adecuada para distintos escenarios de seguridad.

2. Desarrollo

En esta actividad, se realizan distintos cuadros comparativos, los cuales tienen la intención de ser integrados en uno solo.

Metodología Descripción Fases Objetivo Escenarios Orientación
MITRE ATT&CK Marco global basado en tácticas y técnicas de adversarios reales. No lineal (14 tácticas). Ej: Acceso inicial, Persistencia, Exfiltración. Detectar técnicas de ataque y emulación de adversarios. SOC, Threat Hunting y Red Teaming. Defensa / Ofensiva
OWASP WSTG Guía exhaustiva para evaluar seguridad de aplicaciones y servicios web. 12 categorías técnicas: Gestión de identidad, Autenticación, Pruebas API. Pruebas técnicas específicas para software web. Auditorías web, entornos Cloud y desarrollo seguro. Ataque / Evaluación
NIST SP 800-115 Guía técnica para planificar y realizar evaluaciones de seguridad. 1. Planificación
2. Ejecución
3. Post-ejecución
4. Reporting		 Evaluación de controles y validación de políticas. Sectores gubernamentales y organizaciones reguladas (HIPAA, PCI DSS). Evaluación
OSSTMM Manual basado en métricas para la verificación de seguridad operacional. 1. Introducción
2. Interacción
3. Inundación
4. Análisis
5. Reporte (STAR)		 Medición y validación de controles mediante métricas científicas. Seguridad física, redes inalámbricas, telecomunicaciones y factor humano. Evaluación
PTES Estándar que define el proceso de negocio y ejecución de un pentest de alta calidad. 1. Pre-engagement a 7. Reporting (Ciclo completo de explotación). Estandarizar el ciclo de vida de una prueba de penetración comercial. Consultoría profesional de Pentesting y Red Teaming Corporativo. Ataque / Ofensiva
ISSAF Marco integral que vincula herramientas técnicas con procesos de auditoría. 1. Planeación
2. Evaluación (9 capas)
3. Reporte y tratamiento.		 Estandarizar evaluaciones técnicas profundas de sistemas. Auditorías detalladas de infraestructura, SO y bases de datos. Ataque / Evaluación
